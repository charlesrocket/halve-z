# Info

[Halve-Z](https://codeberg.org/charlesrocket/halve-z) is a retro two-column theme for [Zola](https://github.com/getzola/zola). It features search, taxonomies, automatic color schemes, project cards, PWA, and a comment system.

The [documentation](https://codeberg.org/charlesrocket/halve-z/src/branch/trunk/README.md) contains the full set of features and installation manuals.
